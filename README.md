# NLP Emotion Detection

## Overview
This project is an NLP-based Emotion Detection application that predicts the emotion expressed in a given text.

It uses Machine Learning techniques to classify text into different emotion categories.

## Technologies Used
- Python
- Streamlit
- Natural Language Processing (NLP)
- Bag of Words (BoW)
- Logistic Regression
- Scikit-learn
- Pandas
- NumPy

## Model
The model was trained using a Bag of Words approach and Logistic Regression for emotion classification.

The trained model and vectorizer are stored as serialized files and loaded into the Streamlit application.

## Features
- Text input for users
- Emotion prediction
- Interactive Streamlit interface
- Machine Learning-based text classification

## Run Locally

1. Clone this repository.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`
